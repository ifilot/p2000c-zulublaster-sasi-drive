# Microsoft BASIC-80 5.21

`MBASIC.COM` is the unchanged CP/M binary archived as `MBASIC5.COM` at
<https://deramp.com/downloads/microsoft/CPM%20Software/MBASIC5.COM>. It was
imported from the sibling `p2000m-cpm` project, where it is covered by program
execution and file-I/O tests.

Its startup identifies BASIC-80 Rev. 5.21 for CP/M, Microsoft 1977-1981,
created July 28, 1981. Only the host filename was changed.

SHA-256: `29d957fc6899c24f6296a1662a27eca545d85ee3f7d70d2794c9d045d92ff157`

This is historical Microsoft software, not original project code.
